OWASP Top 10 (2021) Labs

A01 - Access Control

IDOR, forced browsing, path traversal.

A02 - Crypto Failures

Weak crypto, secret leaks, cookie flags.

A03 - Injection

SQLi, XSS, command, LDAP, XXE, SSTI.

A04 - Insecure Design

Business logic and flow bypass.

A05 - Misconfig

Security headers, CORS, debug, backups.

A06 - Vulnerable Components

Library detectors and outdated versions.

A07 - Auth Failures

Weak passwords, reset issues, sessions.

A08 - Integrity Failures

Deserialization, SRI, update checks.

A09 - Logging Failures

Verbose errors, log injection.

A10 - SSRF

Server-side request forgery.
