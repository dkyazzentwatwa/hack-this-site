OWASP Top 10 (2021)

A01 Broken Access Control

/api/orders/1002
/admin/

A02 Cryptographic Failures

Find exposed secrets and weak hash usage.

Check /labs/secret-scanner.html
Use /api/hash to compare MD5/SHA1/SHA256

A03 Injection

Reflected XSS, SQLi errors, command injection (simulated).

XSS: ?q=<img src=x onerror=alert(1)>
SQLi: ' OR 1=1 --
Cmd: 127.0.0.1; whoami
Open A03

A05 Security Misconfiguration

Missing headers, exposed backups, CORS mistakes.

Headers: /api/headers
Backup: /backup/config.old
CORS: /api/cors
Open A05

A07 Auth Failures

Weak login, predictable reset tokens, session fixation.

A10 SSRF
