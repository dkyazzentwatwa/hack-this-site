How To Use The Labs

Learning Path

Start with recon, then validate findings with specific labs and endpoints.

1) Discover → 2) Verify → 3) Record → 4) Report
Tip: run your shortcuts on each section page first, then drill into labs.

Reconnaissance

Passive Recon

Learn how to extract metadata, comments, links, and hidden elements.

Targets: /recon/, HTML comments, meta tags, hidden inputs.
Open Recon Lab
Look for: contact info, API endpoints, CMS hints.

Active Recon

Inspect headers, cookies, error messages, methods, and robots/sitemap.

Endpoints: /api/headers, /api/cookies, /api/methods
What to learn: server fingerprints and security header gaps.
